# Customer Segmentation Analysis (SQL + Power BI)

## Overview

This project analyzes customer transaction data to segment customers based on their behavior and identify key revenue drivers. The goal is to provide actionable insights for improving customer retention and maximizing business revenue.

---

## Tech Stack

* SQL Server (Data Cleaning & Transformation)
* Power BI (Data Visualization & Dashboard)
* Excel/CSV (Raw Data Source)

---

## Project Workflow

1. Imported raw transaction data into SQL Server
2. Cleaned and structured data (handled nulls, data types, inconsistencies)
3. Created customer-level metrics:

   * Total Spend
   * Transaction Frequency
   * Average Order Value
   * Recency
4. Performed customer segmentation (High Value, Regular, At Risk)
5. Built an interactive Power BI dashboard for insights

---

## Dashboard Features

* KPI cards for key metrics (Revenue, Customers, Transactions)
* Customer segment distribution
* Revenue contribution by segment
* Revenue trends over time
* Top customers analysis

---

## Key Insights

* High-value customers contribute a large share of total revenue despite being a smaller group.
* Majority of customers fall into low-value segments with minimal revenue impact.
* A portion of customers show high recency, indicating potential churn risk.
* Frequent customers tend to generate significantly higher total spend.

---

## Business Recommendations

* Focus on retaining high-value customers through loyalty programs
* Target mid-tier customers for upselling opportunities
* Re-engage inactive customers to reduce churn
* Optimize marketing strategies based on customer segments
